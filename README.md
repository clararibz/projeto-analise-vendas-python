# Análise de Vendas de uma Loja (Python puro)

Relatório de vendas de uma loja pequena, feito apenas com listas, dicionários, laços e condicionais.

## O que o programa faz
- Faturamento total e ticket médio
- Produto mais vendido
- Faturamento por categoria
- Maior e menor venda
- Classificação das vendas (Alta, Média, Baixa)
